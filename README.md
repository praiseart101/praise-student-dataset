# Student Dataset – Project 3

## Overview

This project contains a fictional dataset of 20 students for the student-dataset assignment. The dataset is saved in CSV format and can be recreated with the included Python script.

## Dataset columns

1. **Student ID** – A unique fictional student identifier.
2. **Department** – The student's department.
3. **Level** – The student's academic level.
4. **Attendance Percentage** – The percentage of classes attended.
5. **Average Examination Score** – The student's average examination score out of 100.

## Project files

- `student_dataset.csv` – The completed dataset containing 20 student records.
- `create_dataset.py` – Python script used to generate the CSV file.
- `README.md` – Project documentation.

## How to generate the CSV

1. Install Python 3.
2. Open a terminal or command prompt in this project folder.
3. Run:

   ```bash
   python create_dataset.py
   ```

The script creates `student_dataset.csv` in the same folder.

## Note

All student records are fictional and intended for educational use. The department names are retained from the supplied source dataset; the student IDs and the arrangement of values are different for this project.
